# BetterBox (email)

Upstream: https://github.com/aidankmcalister/betterbox · https://betterbox.dev

- Gmail API only. **No IMAP**, so a clinic on Outlook or its own mail server
  cannot use this provider. A second email provider is a sibling folder.
- Needs a Google OAuth app and its own database.
- Read and send scopes only. Nothing in this feature deletes or relabels mail.
